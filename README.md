- **Stack:** Python · XGBoost · SMOTE · PCA · SHAP · Scikit-learn · Streamlit
- **Highlights:** Handled severe class imbalance with SMOTE; SHAP explainability for clinical interpretability; deployed as a live app

### 📈 30-Day Stock Price Forecasting
> Multi-model benchmarking system for short-term stock price prediction

- **Stack:** Python · ARIMA · SARIMA · LSTM · TensorFlow/Keras · Statsmodels · Pandas
- **Highlights:** ADF stationarity testing, seasonal decomposition; RMSE/MAE/MAPE per ticker; full model comparison framework

---

### 🎓 Student Test Score Prediction *(Kaggle Competition)*
> Predict student exam performance from demographic & behavioural features to flag at-risk students early

- **Stack:** Python · XGBoost · LightGBM · Random Forest · Scikit-learn · GridSearchCV
- **Highlights:** RMSE = 8.83 among **4,317 global participants**; residual analysis to reduce systematic bias

---

### 🩺 Diabetes Prediction using Machine Learning
> Clinical screening tool to flag high-risk patients from routine health measurements

- **Stack:** Python · Logistic Regression · Random Forest · k-NN · Naive Bayes · GridSearchCV
- **Highlights:** 85%+ accuracy; optimised for **recall** to minimise false negatives in clinical context; full EDA + feature engineering pipeline
